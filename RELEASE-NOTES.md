# SVOI 0.4.0-prebeta.2

Windows x64 · zapret внутри приложения.

- Установка zapret из официального GitHub ZIP в один клик: загрузка, SHA-256, распаковка и проверка состава.
- Автообновление при запуске после первой установки, отдельный переключатель. Работающая версия обновляется после остановки; пользовательские списки сохраняются.
- Системная диагностика Windows: BFE, службы/процессы, драйвер, прокси, TCP timestamps, DoH, hosts и известные конфликты.
- Стандартные тесты сайтов: HTTP/1.1, TLS 1.2, TLS 1.3 и ping. Цели из targets.txt.
- DPI-checkers TCP 16–20 КБ с набором Hyperion, POST 64 КБ и осторожной оценкой таймаута.
- Проверка текущей сети или перебор всех/выбранных стратегий, четыре параллельных запроса, отмена, восстановление прежней стратегии и JSON-отчёт.
- Ручная папка zapret остаётся доступна в дополнительных настройках.

## Как обновиться

В SVOI 0.4.0-prebeta.1 откройте «Настройки» → «Проверить обновления», затем установите скачанную версию. Для 0.3 используйте setup.exe вручную. После обновления откройте zapret → «Скачать и установить».

## Проверки и ограничения

Автотесты проверяют безопасную распаковку, целостность ZIP, сохранение списков, отложенную активацию, отмену и ограничение параллельных задач. Проверена загрузка настоящего релиза Flowseal 1.10.4: 22 стратегии и 16 целей. Системная диагностика проверена в Windows без изменения настроек.

Запуск winws и перебор стратегий требуют администратора; живой перебор WinDivert в этой среде не проверен. TUN и zapret запускаются отдельно. Диагностика не удаляет службы и не меняет hosts/TCP. Неуспешный запрос сам по себе не доказывает DPI-блокировку. APK/IPA отсутствуют.
