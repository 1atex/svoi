# Интернетометр SVOI

Небольшой Go-сервис для настольного клиента. Один фиксированный узел позволяет сравнить прямое соединение и выбранные VPN-серверы без смены активного системного прокси. Адрес клиента: `https://svoi.space/speed/v1/`.

## Метод измерения

- Прямое соединение, затем до трёх серверов последовательно. Два HTTP/1.1 потока внутри каждого маршрута.
- HTTPS-отклик: один прогрев, затем медиана трёх запросов без нагрузки. Это не ICMP-пинг.
- Загрузка: до 4 секунд или 32 МиБ; отдача: до 4 секунд или 16 МиБ. Скорость — фактически переданные биты / время фазы. Отдача учитывает только подтверждённые сервером байты.
- Бюджет — до 48 МиБ полезных данных на маршрут, до 192 МиБ на четыре маршрута. Заголовки, TLS и повторные сетевые передачи добавляют расход. Быстрое достижение лимита отмечается как короткий замер.
- Подготовка Xray ограничена 5 секундами; маршрут — 26 секундами, всё сравнение — 115 секундами. Запуск теста не меняет системные настройки.
- Полные профили используют временное правило для тестового входа: реальный VPN-выход или балансировщик только VPN-выходов. Исходный профиль не меняется; прямой fallback запрещён. Профили с `routing.script` отклоняются.
- При собственном активном TUN сравнение заблокировано: пользователь сначала отключает его сам. Сторонний VPN также нужно отключить. Текущий zapret и прочие сетевые фильтры остаются частью условий теста.
- Уход с экрана/в другую вкладку инструментов, сворачивание в трей, смена профиля или подключение VPN останавливают проверку. Временное ядро завершается, готовые результаты остаются в памяти до выхода из приложения. Фоновых периодических замеров нет.

Результат описывает путь до этого узла, а не максимальную скорость провайдера и не рейтинг протоколов. Его ограничивают канал узла, загрузка сервера, Wi-Fi и другие приложения. Не сравнивайте цифры с тестом на другом узле как равнозначные условия.

## Размещение за существующим Nginx

Сборка из корня проекта (Linux):

```sh
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags '-s -w' -o svoi-speed ./cmd/svoi-speed
```

Установите бинарный файл в `/opt/svoi-speed/svoi-speed` с правами 755, unit `svoi-speed.service` в `/etc/systemd/system/`. Сервис слушает только `127.0.0.1:8792` и отклоняет внешний listen-адрес. DynamicUser, лимиты памяти 96 МиБ и задач 32; восемь активных запросов, ограниченные размеры и тайм-ауты. Его порт не нужен во внешнем firewall.

Сделайте резервную копию виртуального хоста. `nginx-limits.conf` разместите в `/etc/nginx/conf.d/svoi-speed-limits.conf` (контекст http). `nginx-location.conf` — в `/etc/nginx/snippets/svoi-speed.conf`. Добавьте **только в существующий HTTPS server-блок svoi.space**:

```nginx
include /etc/nginx/snippets/svoi-speed.conf;
```

Не создавайте второй процесс на 443 и не заменяйте конфигурации других сайтов. Сжатие и буферизация speed-маршрута отключены. Лимиты Nginx: четыре соединения и 20 запросов/с на IP с burst 40. Узел публичный: проверяйте нагрузку и расходы на трафик; лимиты конкурентности не являются месячной квотой.

```sh
systemctl daemon-reload
systemctl enable --now svoi-speed
curl --fail --retry 3 --retry-connrefused http://127.0.0.1:8792/speed/v1/ping
nginx -t && systemctl reload nginx
curl --fail https://svoi.space/speed/v1/ping
```

Проверьте остальные виртуальные хосты до и после изменения. При откате удалите include из своего server-блока, выполните `nginx -t` и reload, затем остановите unit. Не удаляйте общие файлы Nginx. При обновлении сервиса сохраните старый бинарный файл, замените его через rename и перезапустите только `svoi-speed`.

## Данные и проверки

Сервис передаёт случайный буфер и принимает временные данные. Клиент не отправляет сюда подписку, HWID, список серверов или результаты; access log speed-маршрута выключен. IP источника неизбежно виден серверу при сетевом соединении.

```sh
go test ./internal/speedtest
go test ./backend -run TestSpeed
go test -tags native_core ./...
go vet -tags native_core ./...
```

`TestSpeedThroughRealVLESSCannotFallBackToDirect` проверяет настоящее ядро Xray с корректными и неверными учётными данными. `SVOI_SPEED_LIVE=1 go test ./backend -run TestSpeedLiveNode -v -count=1` — добровольная сетевая проверка до 3 МиБ полезных данных. Остальные тесты используют локальные узлы.
