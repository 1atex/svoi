# SVOI Android Preview 9

- Интернетометр: сравнение напрямую и через до трёх выбранных профилей Xray, загрузка, отдача и HTTPS-отклик до svoi.space.
- Графики фактической скорости по времени с общей шкалой для маршрутов. Загрузка — сплошная линия, отдача — пунктир; в узком окне график находится под цифрами.
- Показаны длительность и объём каждой фазы. Короткие выборки отмечаются; процент не рассчитывается, если загрузка на любом из двух маршрутов измерена слишком коротко.
- Проверка запускается вручную; при уходе с экрана, сворачивании, смене профиля или включении VPN останавливается. Готовые результаты остаются до закрытия приложения.
- До 48 МиБ полезных данных на маршрут, максимум 192 МиБ на сравнение плюс сетевые накладные расходы. Тестовый узел фиксирован; результат не означает максимальную скорость любого сайта.
- Интернетометр находится в «Настройки → Интернетометр». Перед сравнением нужно отключить VPN. Профиль проверяется встроенным временным ядром, без прямого fallback вместо VPN.
- «Что нового» открывает svoi.space с установленной версией; GitHub доступен отдельной кнопкой.

Также перенесено короткое знакомство после установки и обновления: выбор темы и ссылка на изменения. Прежние подписки и тема сохраняются; versionCode 9, пакет и постоянная подпись не изменились.

# Android Preview 7

- Внешний IP в карточке подключения; запрос к ipify по текущему маршруту SVOI. При выборе приложений у других приложений IP может отличаться.

- Обновление поверх Preview 6: прежний package ID и сертификат, versionCode 7. Ранние Preview 5 и ниже могут требовать переноса профиля из-за другой подписи.

## Предыдущие версии

Экспериментальный клиент для Android 8+ (ARM64 и x86_64). Windows-релизы остаются отдельными. Начиная с Preview 6, публичные APK подписываются постоянным ключом и поддерживают обновление из приложения. Application ID: `dev.svoi.app.preview`.

## Обновления Preview 6

В настройках есть проверка версии, загрузка APK с прогрессом и установка. При запуске проверка выполняется не чаще раза в 6 часов. Автозагрузка использует сеть без тарификации (обычно Wi-Fi); ручная загрузка допускает мобильную сеть. Обе автоматические функции можно выключить.

Загрузкой управляет Android DownloadManager: сворачивание UI её не отменяет. Перед установкой APK копируется в закрытое хранилище, проверяются размер, SHA-256, package ID, версия, архитектура и совпадение сертификата с установленным приложением. Android отдельно проверяет подпись при установке. При необходимости пользователь разрешает установку из SVOI, затем подтверждает обновление в системном окне. Тихая установка не выполняется.

**Переход с Preview 5 и более ранних:** сохраните код переноса профиля до удаления старой версии. Ранние APK подписывались временными ключами CI, поэтому установка Preview 6 поверх них может быть невозможна. Постоянная подпись сохраняется во всех следующих выпусках; данные остаются при обновлении поверх приложения.

Для телефона скачайте `-arm64.apk`, для эмулятора x86_64 — `-x64.apk` из [Android Releases](https://github.com/1atex/svoi/releases?q=android-v). Оба публичных APK собираются в release-режиме.

Версия хранится в `config/android-release.json`. Для выпуска увеличьте `versionCode`, задайте `versionName` и отправьте изменения в `android-preview`. Workflow проверит код, обновление на эмуляторе и подпись, затем опубликует APK и `svoi-android-update.json` в отдельном Android-релизе. Windows Latest не меняется. Уже опубликованные файлы не заменяются: для новых бинарников нужна новая версия.

Ключ PKCS12 хранится вне репозитория. CI использует секреты `SVOI_ANDROID_KEYSTORE_BASE64` и `SVOI_ANDROID_KEYSTORE_PASSWORD`; alias — `svoi`. Нужна защищённая резервная копия ключа и пароля: новый ключ несовместим с установленными APK. При локальной release-сборке задаются `SVOI_ANDROID_KEYSTORE` (путь) и `SVOI_ANDROID_KEYSTORE_PASSWORD`. Без них release-сборка прекращается.

## Архитектура

- `backend/` — общие подписки, перенос профилей, хранилище и генерация конфигурации. Windows запускает их через `cmd/svoi-backend/`.
- `mobile/` — один Go runtime в отдельном процессе `:vpn`: общий backend и встроенный Xray 26.10.21. JNI-интерфейс создаётся через gomobile.
- `flutter_client/android/` — системное разрешение VPN, foreground service, TUN-дескриптор, защита исходящих сокетов и выбор приложений.
- `flutter_client/lib/mobile_shell.dart` — мобильная навигация и экраны. Служба VPN продолжает работать после закрытия Activity; остановка доступна в уведомлении.

Конфигурации сохраняют outbounds, loopback и маршрутизацию профиля. Настройку сетевого адаптера выполняет Android VpnService, а не код управления маршрутами Windows. Код профиля совместим с Windows; параметры импортированного профиля сохраняются.

## Изоляция Preview 5

- VPN, Go и хранилище работают в отдельном процессе `:vpn`; UI не загружает Go runtime.
- Binder IPC выполняется вне главного потока. Большие профили передаются через pipe, а не внутри Binder-пакета.
- Закрытие клиента отменяет его пинг. Работающий VPN сохраняется после закрытия Activity.
- После аварии службы клиент восстанавливает связь и читает сохранённые профили. VPN отображается выключенным; команды изменения данных не повторяются автоматически.
- Тест проверяет передачу 2 МиБ, повторное открытие Activity, 20 циклов VPN, отсутствие TUN FD после отключения и восстановление после аварии процесса службы.

## Производительность Preview 4

- Для ARM64-телефонов и эмулятора x86_64 выпускаются отдельные APK в release-режиме (AOT, без VM service). Debug APK используется только для инструментальных тестов CI.
- При сворачивании Android-клиента опрос состояния интерфейсом прекращается, очередь пинга отменяется. Сам VPN продолжает работать. При возвращении состояние перечитывается.
- До двух одновременных HTTPS-проверок вместо четырёх; на устройствах, которые Android помечает как low-RAM, — одна. Отмена доходит до Go/Xray и закрывает запрос; новая проверка не запускается поверх незавершённой очереди.
- Отключён журнал каждого соединения; предупреждения Xray сохранены. Обработчик локального API создаётся один раз на сессию.
- Инструментальные тесты записывают PSS, CPU time, число потоков и файловых дескрипторов после запуска и двадцати циклов VPN. Это диагностика debug-эмулятора, не измерение расхода батареи телефона.

APK доступны напрямую в GitHub Releases; CI также сохраняет artifact `SVOI-Android-preview-release`. Подробности сравнения архитектур и границы измерений: [производительность Android](ANDROID-PERFORMANCE.md).

## Интерфейс Preview 3

Компактная карточка подключения объединяет состояние VPN, кнопку включения и выбор сервера. Подписки видны сразу под ней. У мобильной версии свои размеры шрифтов и кнопок; карточки серверов, профилей и нижняя навигация используют единое оформление. При увеличении системного шрифта блок подключения перестраивается вертикально.

## Возможности Preview 2

- Проверка пинга, прогресс, остановка очереди и сортировка серверов по задержке. Проверки не переключают действующий VPN.
- Бежевая подсветка мобильного меню.
- Настройка HWID, ОС, модели, языка и User-Agent в активном профиле. Можно отключить четыре заголовка устройства; User-Agent остаётся отдельным параметром. Параметры применяются при следующем запросе подписки, сохраняются и переносятся по коду.
- Профили с количеством подписок и серверов, видимым активным профилем и постоянным порядком. Поиск сохраняет видимый текст фильтра.

## Проверки без телефона

Workflow `.github/workflows/android.yml` собирает AAR и APK, выполняет тесты Flutter и запускает эмулятор Android 10. Инструментальный тест импортирует VLESS-профиль, создаёт VPN и двадцать раз подключается к изолированному Xray-серверу. HTTP-адрес теста достижим только через туннель. Во время первого подключения выполняются две HTTPS-проверки и проверяется отмена до старта, после чего проверяется, что VPN продолжает передавать трафик. Go-тесты дополнительно проверяют успешную маршрутизацию проб, закрытие сетевого соединения при отмене, освобождение ресурсов по тайм-ауту и отсутствие конфликтов портов. Дополнительные тесты проверяют отклонение повреждённого APK и чужой подписи, выбор архитектуры и сохранность профилей при установке более новой debug-сборки поверх предыдущей. Сертификаты публичных release APK отдельно проверяются через apksigner. APK публикуются только после успешных проверок.

В инструментальном тесте Activity запускается с программной отрисовкой для серверного эмулятора. Публичные APK используют штатное аппаратное ускорение. При затянувшемся тесте сохраняется снимок Java-потоков; время выполнения ограничено.

Локальная сборка требует JDK 17, Android SDK, NDK 28.2.13676358, Go 1.27.3 и Flutter 3.47.7. Точные команды закреплены в workflow. `scripts/prepare-android.py` проверяет SHA-256 архива ядра перед извлечением GeoIP/GeoSite. Архивы, AAR и APK не коммитятся.

## Ограничения Preview

- Нет проверки на физических устройствах и прошивках разных производителей. Эмулятор не проверяет энергосбережение, мобильную сеть, сон устройства и поведение OEM.
- Автоматическое восстановление после смены сети/перезагрузки пока не заявляется; при проблемах переподключите VPN.
- HTTPS-пинг запускается для одного сервера или видимого списка: до двух проверок одновременно, сетевой лимит 4 секунды. Время измеряет GET-запрос после запуска Xray; это не ICMP-пинг. Ошибка не блокирует ручное подключение.
- Список приложений показывает приложения с launcher-иконкой. Изменения применяются после переподключения.
- Windows zapret, системный прокси и Windows-установщик обновлений на Android отсутствуют.
- Нет QR-сканера и публикации в Google Play.

Для тестировщика: проверить импорт ссылки и кода с ПК, два-три цикла VPN, работу с выключенным экраном, Wi-Fi → мобильная сеть, разрешение VPN после отмены и списки приложений. Не публиковать подписки, коды переноса и конфигурации с ключами в открытых issue.
