# Android Preview 2

Экспериментальный клиент для Android 8+ (ARM64 и x86_64). Windows-релизы остаются отдельными. APK из workflow `Android preview` предназначен для тестирования, подписан отладочным ключом CI и имеет отдельный application ID `dev.svoi.app.preview`. Это не ключ для публичных обновлений: перед первым стабильным Android-релизом нужен постоянный закрытый ключ подписи. При смене отладочного ключа потребуется удалить прежний Preview; перед удалением сохраните код переноса профиля.

## Архитектура

- `backend/` — общие подписки, перенос профилей, хранилище и генерация конфигурации. Windows запускает их через `cmd/svoi-backend/`.
- `mobile/` — один Go runtime: общий backend и встроенный Xray 26.10.21. JNI-интерфейс создаётся через gomobile.
- `flutter_client/android/` — системное разрешение VPN, foreground service, TUN-дескриптор, защита исходящих сокетов и выбор приложений.
- `flutter_client/lib/mobile_shell.dart` — мобильная навигация и экраны. Служба VPN продолжает работать после закрытия Activity; остановка доступна в уведомлении.

Конфигурации сохраняют outbounds, loopback и маршрутизацию профиля. Настройку сетевого адаптера выполняет Android VpnService, а не код управления маршрутами Windows. Код профиля совместим с Windows; параметры импортированного профиля сохраняются.

## Возможности Preview 2

- Проверка пинга, прогресс, остановка очереди и сортировка серверов по задержке. Проверки не переключают действующий VPN.
- Бежевая подсветка мобильного меню.
- Настройка HWID, ОС, модели, языка и User-Agent в активном профиле. Можно отключить четыре заголовка устройства; User-Agent остаётся отдельным параметром. Параметры применяются при следующем запросе подписки, сохраняются и переносятся по коду.
- Профили с количеством подписок и серверов, видимым активным профилем и постоянным порядком. Поиск сохраняет видимый текст фильтра.

## Проверки без телефона

Workflow `.github/workflows/android.yml` собирает AAR и APK, выполняет тесты Flutter и запускает эмулятор Android 10. Инструментальный тест импортирует VLESS-профиль, создаёт VPN и трижды подключается к изолированному Xray-серверу. HTTP-адрес теста достижим только через туннель. Во время первого подключения выполняются четыре HTTPS-проверки, после чего проверяется, что VPN продолжает передавать трафик. Go-тесты дополнительно проверяют успешную маршрутизацию проб, освобождение ресурсов по тайм-ауту и отсутствие конфликтов портов. APK загружается в artifacts только после успешного теста.

Локальная сборка требует JDK 17, Android SDK, NDK 28.2.13676358, Go 1.27.3 и Flutter 3.47.7. Точные команды закреплены в workflow. `scripts/prepare-android.py` проверяет SHA-256 архива ядра перед извлечением GeoIP/GeoSite. Архивы, AAR и APK не коммитятся.

## Ограничения Preview

- Нет проверки на физических устройствах и прошивках разных производителей. Эмулятор не проверяет энергосбережение, мобильную сеть, сон устройства и поведение OEM.
- Автоматическое восстановление после смены сети/перезагрузки пока не заявляется; при проблемах переподключите VPN.
- HTTPS-пинг запускается для одного сервера или видимого списка: до четырёх проверок одновременно, сетевой лимит 4 секунды. Время включает запуск отдельного экземпляра Xray и HTTPS-запрос; это не ICMP-пинг. Ошибка не блокирует ручное подключение.
- Список приложений показывает приложения с launcher-иконкой. Изменения применяются после переподключения.
- Windows zapret, системный прокси и Windows-установщик обновлений на Android отсутствуют.
- Нет QR-сканера, Google Play и автоматического скачивания APK-обновлений в этой сборке.

Для тестировщика: проверить импорт ссылки и кода с ПК, два-три цикла VPN, работу с выключенным экраном, Wi-Fi → мобильная сеть, разрешение VPN после отмены и списки приложений. Не публиковать подписки, коды переноса и конфигурации с ключами в открытых issue.
