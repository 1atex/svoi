# Структура исходников

Текущее приложение для Windows состоит из Flutter-интерфейса, локального Go backend и Xray. Инструкция сборки и тестирования — в [flutter_client/README.md](../flutter_client/README.md).

| Путь | Назначение |
| --- | --- |
| `flutter_client/` | Интерфейс, Windows runner, тесты, установщик и сборка текущего приложения |
| Корневые `*.go` | Подписки, профили, Xray, TUN, маршрутизация, zapret, обновления и автозапуск |
| Корневые `*_test.go` | Проверки backend и интеграции с Windows |
| `go.mod`, `go.sum` | Зависимости Go и их контрольные суммы |
| `prepare-core.ps1`, `core/` | Загрузка закреплённой версии Xray, сведения об источнике и лицензии |
| `assets/`, `licenses/` | Иконки, исходники оформления и лицензии зависимостей |
| `.github/workflows/release.yml` | Проверки, сборка и публикация текущего Windows-клиента |

## Прежний веб-интерфейс

`web/` пока встроен в Go-сервис через `go:embed`; `desktop_windows.go` используется при сборке без `native_core`. Это действующие зависимости исходников. Отдельные установщик и выпуск WebView-клиента больше не поддерживаются.

`package.json`, `package-lock.json` и `tests/` нужны для регрессионных проверок этого интерфейса. Node.js не входит в приложение. Проверки из корня репозитория:

```powershell
npm ci --ignore-scripts
npm test
go test ./...
go test -tags native_core ./...
go vet ./...
```

Текущая сборка использует `desktop_native_windows.go` и тег `native_core`. Файлы `*_windows.go` и `*_other.go` выбираются Go по платформе: это не дубликаты. Удалять их или тесты ради сокращения списка файлов не требуется.
