# Проверка установки SVOI VPN-расширения на iPhone

`SVOI-TunnelCheck-0.1.0.ipa` — отдельная диагностика. Это **не iOS-версия SVOI**: в ней нет Xray, подписок и подключения к VPN-серверу. Задача — проверить фактический запуск собственного Network Extension после подписи выбранным установщиком.

## Что проверяется

1. В пакете присутствует `PlugIns/PacketTunnel.appex`.
2. iOS разрешает сохранить VPN-конфигурацию `NETunnelProviderManager`.
3. iOS запускает наш `NEPacketTunnelProvider`.
4. Приложение получает контрольный ответ именно от этого расширения через `sendProviderMessage`.

Только успешный шаг 4 отображается как «Туннель доступен». Это доказывает запуск расширения с текущей подписью на конкретном телефоне, но не поддержку всех функций будущего клиента.

Интернет и DNS не перенаправляются. Расширению назначается только зарезервированная для документации сеть `192.0.2.0/24`; default route отсутствует. Не используйте адреса этой тестовой сети во время проверки. Исходящих сетевых запросов, аналитики, телеметрии и сбора подписок нет.

## Установка через Bullfrog / Sideloadly

Переподпишите IPA выбранным способом. Не удаляйте расширение `.appex`; установщик должен согласованно подписать приложение и расширение, сохранив связку их идентификаторов. Не присылайте сертификат, Apple ID, пароль или приватный ключ разработчику SVOI.

Откройте установленное приложение, нажмите «Проверить туннель», подтвердите системный запрос. Если появился статус «Туннель доступен», отключите тест и удалите тестовую VPN-конфигурацию отдельной кнопкой. При ошибке скопируйте диагностику встроенной кнопкой.

Установка IPA и наличие VPN у самого установщика не гарантируют разрешение для нашего расширения. Бесплатный Personal Team штатно не предоставляет Network Extensions; для Bullfrog подтверждения отдельного способа выдачи этого разрешения не найдено. Требуется проверка результата, а не предположение по названию установщика. TrollStore по заявленной поддержке не подходит для iPhone 17 Pro с iOS 27.

## Сборка

На Mac с Xcode и Homebrew:

```sh
brew install xcodegen
bash scripts/build-ios-tunnel-check.sh
```

Получится IPA с ad hoc подписью, **без Apple provisioning profile**. Её нельзя считать готовой к установке на обычный iPhone без последующей корректной подписи. Приватные или обходные entitlements в проект не добавляются.

Для разработки в Xcode с собственным аккаунтом откройте сгенерированный `apple/ios-tunnel-check/SvoiTunnelCheck.xcodeproj`, настройте Team и provisioning для обеих targets, включите подписание вместо `CODE_SIGNING_ALLOWED=NO`. Network Extension entitlement должен быть разрешён профилями, простого наличия ключа в `.entitlements` недостаточно.

Источники: [Apple — настройка Network Extensions](https://developer.apple.com/documentation/xcode/configuring-network-extensions/), [разъяснение Apple о Personal Team](https://developer.apple.com/forums/thread/128767), [Bullfrog](https://www.ios222.com/), [поддерживаемые версии TrollStore](https://github.com/opa334/TrollStore).
