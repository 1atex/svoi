# SVOI для iOS — development preview

Это исходники первого клиента iOS, а не прежнего приложения Tunnel Check. Интерфейс написан на SwiftUI. Общий Go backend и встроенный Xray переиспользуются из Android-версии.

## Сборка на Mac

Нужен Mac Apple Silicon с полным Xcode. Откройте Xcode и завершите первоначальную настройку. Command Line Tools без Xcode недостаточно.

В Терминале из корня проекта:

```sh
bash START-IOS.command
```

Скрипт устанавливает необходимые инструменты, проверяет SHA-256 загружаемого Go и ресурсов Xray, собирает `SvoiMobile.xcframework`, приложение и `PacketTunnel.appex`. Flutter, Android Studio и платный Apple Account для этого шага не требуются. Homebrew может запросить пароль администратора Mac.

Если инструменты уже установлены:

```sh
bash scripts/build-ios.sh
```

Результат: `releases/ios-v0.1.0-preview.6/SVOI-0.1.0-preview.6-ios-arm64-unsigned.ipa`. Журнал Xcode: `.tools/ios-client-build.log`. При повторной упаковке перенесите прежнюю IPA в другое место: готовый пакет не перезаписывается.

Проект Xcode создаётся в `apple/ios-client/SVOI.xcodeproj`. Версии инструментов и ресурсов закреплены в `config/ios-release.json`. SDK iOS 16+ достаточен для компиляции используемых API; совместимость Xcode для отладки подключённого iPhone проверяйте отдельно по [таблице Apple](https://developer.apple.com/xcode/system-requirements).

## Что реализовано

- Добавление нескольких подписок по ссылке, импорт текстовых конфигураций и файлов, перенос профилей кодом SVOI1.
- Сохранение нескольких профилей и параметров устройства, настройка отправки HWID и других заголовков подписки.
- Список серверов, поиск, просмотр исходной конфигурации через контекстное меню, GET-проверка задержки через профиль до двух серверов одновременно при отключённом VPN.
- Подключение, отключение и переключение сервера через отдельный Network Extension с Xray; сохранение маршрутизации профиля.
- Отображение метаданных подписок, обновление при запуске, внешний IP и отдельный контрольный запрос доступности интернета.
- Главный экран объединяет кнопку подключения, выбранный сервер и подписки с компактными строками серверов. Сворачивание подписок сохраняется отдельно для каждого профиля. Обновление, поддержка провайдера и удаление доступны в заголовке подписки; удаление требует подтверждения.
- Три вкладки: подключение, инструменты и настройки. Общий профиль находится в настройках; IP и проверка интернета открываются по кнопке «Подробнее», без автоматического запроса IP при каждом возвращении на главный экран.
- Графитовые поверхности, три спокойных акцента, отдельная AMOLED-тема и системные варианты иконки SVOI.
- Единый набор внутренних иконок на всех экранах; контурный и двухцветный стили переключаются отдельно от темы.
- Кнопка включения с отдельными состояниями подключения, отмены и переключения сервера; IP с копированием и обновлением.
- Импорт при первом запуске, системная вставка из буфера, явное меню конфигурации, прогресс проверки задержки, поиск и сортировка серверов.
- Поддержка Dynamic Type, VoiceOver, Reduce Motion и ссылка на канал Telegram.

В инструментах доступны сравнение скорости напрямую и через до трёх профилей, HEAD-проверка сайта в текущем подключении и сравнение 12 DNS-адресов. Все проверки запускаются вручную и отменяются при уходе с экрана; DNS-тест не меняет настройки iOS. Для чистого сравнения скорости и DNS отключите VPN.

На iOS нет Windows zapret и системной смены DNS, выбора отдельных приложений и установки обновлений из APK. Автоматическое обновление IPA не реализовано. Подключение не включается автоматически при запуске приложения.

Проверка списка серверов при активном VPN временно отключена: запросы основного приложения иначе проходили бы через уже работающий туннель и искажали сравнение. Проверка текущего интернета и внешний IP остаются доступны при подключении.

## Подпись после сборки

Пакет имеет только локальную ad hoc подпись для проверки целостности. Это **не Apple Ad Hoc distribution**, provisioning-профилей Apple в нём нет. Для обычного iPhone необходимо отдельно подписать приложение и вложенное расширение подходящими профилями одной команды:

- `dev.svoi.app.ios`
- `dev.svoi.app.ios.PacketTunnel`

Оба профиля должны разрешать `com.apple.developer.networking.networkextension = [packet-tunnel-provider]`. Для Ad Hoc распространения UDID телефона должен быть зарегистрирован и включён в профили. Установщик должен сохранить `PlugIns/PacketTunnel.appex`. Идентификатор расширения читается из установленного пакета, поэтому согласованное изменение Bundle ID при переподписи поддерживается.

Сертификаты, приватные ключи, пароли и пользовательские подписки не помещаются в репозиторий или исходный архив. [Настройка Network Extension у Apple](https://developer.apple.com/documentation/xcode/configuring-network-extensions/), [создание Ad Hoc профиля](https://developer.apple.com/help/account/provisioning-profiles/create-an-ad-hoc-provisioning-profile).

## Проверка на телефоне

После правильной подписи импортируйте подписку, проверьте задержку, включите VPN и выполните отдельную проверку интернета. Повторите подключение и отключение несколько раз, переключите сервер, заблокируйте экран, смените Wi-Fi на мобильную сеть. Закрытие интерфейса не должно останавливать работающее расширение.

Состояние «VPN включён» означает запуск расширения и ядра; доступность удалённого сервера подтверждается отдельно контрольным запросом. `permission denied` при чтении или сохранении VPN — ошибка разрешений подписи, а не результат проверки сервера.

CI собирает настоящие arm64 приложение и расширение без provisioning. Go-проверка на macOS передаёт UDP-пакеты через тот же формат канала и Xray, проверяя ответ и пять циклов остановки/запуска без привилегированного TUN. Это не заменяет проверку iOS Network Extension на правильно подписанном физическом устройстве. Потребление памяти расширения и поведение при смене сети требуют такой проверки.

## Энергопотребление и нагрев

В preview.6 буфер приёма PacketPump выделяется один раз на соединение. Исходящие пакеты передаются через `sendmsg` двумя векторами — заголовок и исходный пакет — без создания склеенного `Data` для каждого пакета. Чтение событийное, ответы передаются в NEPacketTunnelFlow пакетами до 64; при ошибке источник событий закрывается. Переполненный неблокирующий канал не опрашивается в цикле ожидания.

Подробный access-журнал и DNS-журнал Xray отключены в конфигурации iOS, предупреждения и ошибки сохранены. Маршруты, DNS и проверки узлов из подписки не удаляются: их изменение может нарушить переключение узлов. Геобазы проверяются побайтово при смене версии ресурсов, а при повторном подключении используются отметка версии и размеры файлов. Проверки задержки останавливаются при запуске VPN, смене вкладки или уходе в фон. Автообновление подписок при уходе в фон прекращается между запросами; уже выполняющийся запрос Go завершается по своему тайм-ауту.

Ограничение памяти Go и GC не повышены: расширение работает с тем же мягким лимитом 32 МиБ. Снижение копирований не является измеренным процентом экономии батареи и не гарантирует отсутствие нагрева на любом протоколе.

Для сравнения на реальном iPhone используйте одну версию iOS, один сервер, одну сеть и одинаковую нагрузку. Отдельно сравните 10 минут простоя с заблокированным экраном и 10 минут воспроизводимого трафика, без параллельных тестов скорости и пинга. В Instruments измеряйте CPU, аллокации и энергопотребление процесса приложения и PacketTunnel отдельно; учитывайте thermal state, зарядку, яркость и уровень сигнала. Симулятор проверяет интерфейс и формат пакетов, а не тепловой режим телефона.

## Проверка интерфейса

Workflow запускает отдельный SVOIInterfacePreview в iOS Simulator на компактном iPhone и iPhone Pro. Проверяются кнопка включения, выбор и переключение сервера, пустое состояние, отключение при пустом списке серверов, импорт, профиль, выбор акцента, крупный системный текст и альбомная ориентация. Скриншоты и логи сохраняются в артефактах iOS-interface-compact и iOS-interface-pro.

Демонстрационные адреса и серверы включаются только флагом компиляции SVOI_UI_PREVIEW в отдельной схеме. В распространяемой IPA этого флага и демонстрационного ядра нет. Эти тесты проверяют интерфейс, а не реальное VPN-соединение.
