# SVOI · 12-секундный launch film

Утверждённая короткая версия: 1920 × 1080, 60 fps, 24 бита при 120 BPM. Русские надписи, без диктора. Графит, янтарь, мятный акцент подключённого состояния.

| Время | Действие |
| --- | --- |
| 0–1,5 с | Wordmark сжимается в точку; клик раскрывает приложение. |
| 1,5–4 с | Серверы, страны, избранное, выбор Finland. |
| 4–7 с | Панель раскрывается на музыкальном акценте; кнопка питания и состояния подключения. |
| 7–9 с | Просмотр JSON, вкладка «Исходная», прокрутка, закрытие. |
| 9–12 с | Подключение собирается в капсулу; «На связи со своими.»; возврат в логотип. |

## Изображение

Рендерер — `flutter_client/tool/launch_film_test.dart`. Детерминированная 2D-композиция на Flutter Canvas: изменение размеров, позиции, радиуса, маски и один курсор. Без монтажных склеек, crossfade, blur-in, 3D-вращений и частиц. Логотип использует утверждённый PNG как плоскую текстуру.

Это стилизованная демонстрация интерфейса, а не запись живого VPN-сеанса. Цвета, формы, названия контролов и состояния взяты из приложения. Флаги получены из настоящего виджета CountryMark. В демонстрации нет результатов замеров и настоящих ключей. Фрагмент routing основан на тестовом профиле из `profile_test.go`; показан просмотр JSON, не отсутствующий в приложении редактор.

720 кадров. Первый и последний исходные PNG идентичны. В H.264 возможна небольшая разница квантования на стыке. Громкость звука на границе плавно сведена к нулю для предотвращения щелчка; музыкальная фраза не заявляется бесшовной.

## Музыка

Использован фрагмент 36,11–48,11 с. Анализ периодичности аудио подтвердил сетку 120 BPM; скорость воспроизведения не изменялась. На 4-й секунде видео приходится музыкальный акцент, на 7–9-й секунде громкость снижена для просмотра конфигурации. Дополнительно синтезированы тихие клики интерфейса.

Исходная дорожка: `https://assets.mixkit.co/music/173/173.mp3`.
SHA-256: `9606a32daac982a5cc42ab4f333ca427ee394f9242a433617007952f4b20ea10`.

Музыка лицензируется отдельно от MIT-кода SVOI. Исходный MP3 и промежуточный аудиомикс не включены в публичный репозиторий. Для распространения ролика используйте разрешённые лицензией каналы, например веб и социальные сети.

## Повторный рендер

Нужны зависимости проекта Flutter, Segoe UI / Consolas на Windows, FFmpeg в PATH, Python и NumPy. Видеоинструменты не входят в runtime приложения.

Из `flutter_client`:

```powershell
$env:CI = 'true'
$env:SVOI_FILM_PREVIEW = '0'
flutter test --no-pub tool/launch_film_test.dart
```

`SVOI_FILM_PREVIEW=1` сохраняет только опорные кадры для быстрой проверки. Полный режим создаёт 720 PNG в `.ui-preview/launch/frames/`.

Из корня репозитория, после получения указанной дорожки Mixkit:

```powershell
python flutter_client/tool/launch_audio.py .ui-preview/launch/audio/better-times-are-coming.mp3 .ui-preview/launch/audio/film-mix.wav
New-Item -ItemType Directory -Force releases/media
ffmpeg -y -framerate 60 -i .ui-preview/launch/frames/%04d.png -frames:v 720 -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -threads 4 -movflags +faststart releases/media/SVOI-launch-12s-silent.mp4
ffmpeg -y -i releases/media/SVOI-launch-12s-silent.mp4 -i .ui-preview/launch/audio/film-mix.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 256k -t 12 -movflags +faststart releases/media/SVOI-launch-12s-1080p.mp4
```

Выход: основной MP4 со стереозвуком 48 kHz и версия без музыки. Итоговые файлы лежат в игнорируемом каталоге `releases/media/`. Это медиаартефакты: новая версия VPN-клиента для них не выпускается.
