# SVOI 0.7.1 RC3

- Исправлена кнопка подключения WARP: теперь используется тот же компонент, что и на экране VPN, с круговой шкалой, анимацией включения и реакцией на наведение и нажатие.
- На подключённой кнопке отображается «Подключён». При отключённом WARP кнопка остаётся без лишних подписей.
- Анимации учитывают системное уменьшение движения. В состоянии покоя постоянная анимация не запускается.

Официальный компонент WARP и возможности RC2 сохранены. Подписки, выбранная тема и настройки подключения остаются на месте.

Linux x64: DEB и переносимый tar.gz. Обновление устанавливается из пакета вручную.
