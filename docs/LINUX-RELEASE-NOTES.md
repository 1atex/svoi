Первая экспериментальная сборка SVOI для Linux x86_64.

- `.deb` для Ubuntu 22.04+ и совместимых Debian-систем: меню приложений и сетевые права Xray настраиваются при установке.
- Переносимый `.tar.gz` со всеми файлами приложения и ядром. Для TUN требуется однократная настройка `setcap` по инструкции.
- Подписки, импорт профилей, VLESS/VMess/Trojan/Shadowsocks/Hysteria2, проверка задержки через конфигурацию, внешний IP и исключения сайтов.
- Восемь тем, хэллоуинская кнопка и прямой переход в Telegram.
- TUN и локальные HTTP/SOCKS-прокси. Windows zapret, выбор отдельных приложений и изменение системного DNS в Linux Preview отсутствуют.
- Данные хранятся в каталоге пользователя. GUI работает без sudo. В `.deb` право исполнения ядра с сетевыми capabilities ограничено root и группой sudo.

Проверки: Go и Flutter, реальный запуск GTK под Xvfb/Openbox, закрытие окна с остановкой сервиса, трафик через локальный VLESS-стенд, пять циклов TUN в изолированном network namespace с ядром от обычного пользователя. Это не проверка реального VPN-провайдера и всех рабочих столов Linux.

**DNS остаётся под управлением Linux.** Локальные DNS-серверы могут обходить TUN; защита от утечек DNS не заявляется. Обновления Linux пока устанавливаются вручную. Полная инструкция находится в [LINUX.md](https://github.com/1atex/svoi/blob/main/docs/LINUX.md) и внутри архива.
