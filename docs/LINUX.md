# SVOI для Linux

Первая экспериментальная сборка x86_64 для Ubuntu 22.04+ / совместимых Debian-систем. GUI работает через GTK 3 (X11/Wayland). Фактическая проверка сборки выполняется на Ubuntu под Xvfb и в изолированном сетевом пространстве; это не проверка всех дистрибутивов и рабочих столов.

## Установка

Скачайте `.deb` из Linux-релиза и установите локальный файл:

```sh
sudo apt install ./SVOI-0.6.0-preview.1-linux-amd64.deb
svoi
```

В меню приложений появится SVOI. Установщик выдаёт только ядру Xray `CAP_NET_ADMIN` и `CAP_NET_RAW` для TUN; GUI и локальный сервис работают от вашего пользователя. Исполнение этого ядра ограничено владельцем root и группой sudo: для TUN обычный пользователь должен входить в группу sudo. Не запускайте GUI через sudo.

## Переносимый архив

Распакуйте весь архив, сохраняя `backend`, `data` и `lib` рядом с `svoi`. Нужны GTK 3, libayatana-appindicator3 и обычные зависимости Flutter Linux. Ручной HTTP/SOCKS-прокси работает без дополнительных прав. Для TUN администратор один раз выдаёт права ядру (повторить после замены ядра/распаковки новой версии):

```sh
sudo setcap cap_net_admin,cap_net_raw+ep /полный/путь/svoi/backend/core/xray
./svoi/svoi
```

Не выдавайте эти права файлам из непроверенного источника. Удалить права можно `sudo setcap -r /полный/путь/svoi/backend/core/xray`.

## Возможности и ограничения

- Подписки, JSON/URI, перенос профилей, пинг через конфигурацию, внешний IP, темы и Telegram.
- TUN со штатной маршрутизацией Xray, ручные локальные HTTP/SOCKS-прокси, исключения сайтов.
- Системный DNS остаётся под управлением Linux. В первой версии SVOI не меняет `resolv.conf` и настройки systemd-resolved. DNS локальной сети может идти напрямую; не рассматривайте эту сборку как защиту от утечек DNS.
- Выбор отдельных приложений, изменение системного DNS, автоматическая установка обновлений, автозапуск и Windows zapret в Linux Preview отсутствуют.
- Меню трея работает при поддержке AppIndicator рабочим столом. Кнопка сворачивания минимизирует окно, чтобы его можно было вернуть и без расширения трея. Закрытие окна останавливает VPN и сервис.
- Данные: `$XDG_DATA_HOME/svoi` или `~/.local/share/svoi`. Можно переопределить через `SVOI_DATA`.
- Linux-сборки публикуются отдельно от Windows и Android. Обновление пока устанавливается вручную.

## Сборка из исходников

Нужны Go 1.26+, Flutter 3.47.7, Python 3, curl, unzip, clang, cmake, ninja-build, pkg-config, libgtk-3-dev, libayatana-appindicator3-dev и libstdc++-12-dev. Выполните `bash scripts/build-linux.sh` на Linux x86_64. Скрипт проверяет SHA-256 закреплённого Xray и собирает `.deb` и `.tar.gz` в `releases/linux-v0.6.0-preview.1/`.
