# SVOI macOS development preview

Первая сборка предназначена для Mac с Apple Silicon (M-серия), macOS 13 и новее. Это отдельный тестовый канал; Windows и Android не получают её как обновление.

## Установка

Откройте DMG, перенесите **SVOI.app** в **Программы** и запускайте приложение целиком. Xray и помощник прокси находятся внутри пакета. Профили сохраняются в `~/Library/Application Support/SVOI`, а не рядом с приложением.

Сборка пока имеет локальную ad hoc подпись, без Developer ID и notarization. При загрузке из интернета Gatekeeper может заблокировать первый запуск. Используйте штатное разрешение в «Системные настройки → Конфиденциальность и безопасность», если доверяете источнику. Отключать защиту всей системы не требуется. Наличие ad hoc подписи не означает проверку Apple.

## Подключение

- **Системный прокси** — выбран по умолчанию. Подключает браузеры и приложения, учитывающие HTTP/HTTPS-прокси macOS. Это не весь трафик: UDP и приложения, игнорирующие прокси, не покрываются.
- **Ручной прокси** — SOCKS5/HTTP-адреса доступны в подробностях соединения; их можно указать в отдельном приложении.
- Полный TUN через Network Extension, разделение по приложениям, автозапуск и автоматическая установка обновлений в этой сборке не реализованы. Запуск от root не добавляет TUN.

При изменении системного прокси macOS может запросить учётные данные администратора в собственном диалоге. SVOI не получает и не сохраняет пароль. Отдельный помощник удерживает разрешение до полного завершения SVOI; включение и отключение соединения используют тот же помощник и разрешение. Он сохраняет исходные словари прокси для текущих включённых Wi-Fi/Ethernet-подключений, применяет loopback-прокси, отключает PAC/автообнаружение/SOCKS на время соединения и восстанавливает исходные значения при отключении. Исключения прокси сохраняются. Если пользователь сам изменил словарь прокси, SVOI не перезаписывает его при восстановлении.

Помощник восстанавливает настройки при закрытии канала с backend, в том числе при аварийном завершении backend. Если сам помощник был принудительно завершён или Mac выключился, сохранённый снимок используется при следующем запуске. Если восстановление не удалось, отключите прокси вручную в настройках текущего сетевого подключения и повторно запустите SVOI.

Красная кнопка окна скрывает приложение; VPN продолжает работать. Пункт **«Отключить и выйти»** в меню SVOI и **Cmd+Q** завершают соединение. В фоне интернетометр отменяется, постоянные замеры не выполняются.

## Сборка на Mac

Установите полный Xcode с command-line tools, Flutter версии из `config/macos-release.json`, Go 1.27.3 и Python 3.11+. Затем из корня репозитория:

```sh
bash scripts/build-macos.sh
```

Результат: `releases/macos-v0.6.0-preview.2/SVOI-0.6.0-preview.2-macos-arm64.dmg` и SHA-256. Данные официального пакета Xray загружаются с фиксированной контрольной суммой. Само ядро собирается из закреплённого исходного коммита с [исправлением ранней остановки](../patches/macos-xray/README.md); его маркер сборки — `1b1647c-svoi-macos.1`. Повторная упаковка не перезаписывает существующий DMG.

Workflow `macOS development preview` создаёт артефакт для ручной проверки, не публикует GitHub Release и не меняет Latest. Проверяются компиляция Swift/Go/Flutter, модель восстановления прокси и настоящий VLESS-трафик в ручном режиме. На отдельной CI-машине проверяются три цикла изменения и восстановления системного прокси с одним помощником и одним запросом авторизации, а также восстановление при закрытии канала. Показ системного диалога обычному пользователю и сон/пробуждение требуют проверки на реальном Mac. После полного завершения SVOI первое подключение может снова потребовать разрешение macOS.

## Следующий этап Apple VPN

При реализации через Apple Network Extension для распространения macOS вне App Store нужен Packet Tunnel System Extension с корректной подписью и provisioning. Альтернатива для прямого распространения — имеющийся в Xray utun с отдельным привилегированным помощником; в этой preview он ещё не включён и требует проверки выдачи прав и восстановления маршрутов на Mac. Для iOS — Packet Tunnel App Extension, общий движок в XCFramework и связь с Flutter через Swift. Поддержка установки IPA зависит от фактически выданного Network Extension entitlement, а не только от названия установщика.

TrollStore не заявляет поддержку iOS 17.0.1+; для проверочного iPhone 17 Pro с iOS 27 этот способ не подходит. Работа собственного туннеля при подписи бесплатным Apple ID через Bullfrog/Sideloadly не подтверждена. Перед переносом всего iOS-интерфейса нужен тест минимального расширения на реальном телефоне с выбранным provisioning profile.
