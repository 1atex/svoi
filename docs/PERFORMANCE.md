# Архив измерений производительности 0.4

Замеры относятся к Go API и прежнему WebView-интерфейсу. Они не описывают производительность текущего Flutter-клиента. Команды ниже выполняются из корня репозитория.

Измерения 23 октября 2026, Windows x64, Ryzen 5 5600X, Go 1.26.
Сравнение с 0.4.0-prebeta.2: одинаковые синтетические данные, три запуска Go benchmark.
Это время обработки локального API, а не скорость VPN или время запуска окна.

| Сценарий | До | После |
|---|---:|---:|
| Опрос VPN, 2 000 серверов: медиана | 75,7 мкс | 1,71 мкс |
| Выделения памяти на этот запрос | 388 581 байт | 1 473 байта |
| zapret, 4 000 результатов: медиана | 1,41 мс | 0,191 мс |
| Ответ zapret для интерфейса | 788 279 байт | 79 116 байт |
| Выделения памяти на запрос zapret: медиана | 1 738 028 байт | 134 508 байт |
| Перестроенные строки при одном новом результате пинга, список 1 000 серверов | 1 000 | 1 |

Выделения на запрос не равны потреблению RAM всего приложения. Бенчмарк включает
HTTP ResponseRecorder; цифры годятся для сравнения реализаций, а не прогноза нагрузки
на любом компьютере. DOM-тесты выполняются в jsdom: проверяют число заменённых узлов,
сохранение фокуса и поведение, но не FPS/отрисовку WebView2.

## Что изменено

- Опрос VPN не копирует все конфигурации и журнал. Журнал загружается по запросу.
- Список серверов строится при открытии раздела. Неизменившиеся строки сохраняются;
  поиск использует кеш нормализованных названий, источники индексируются через Map.
- Неизменившийся статус VPN не перерисовывает карточку. Таймер времени работы нужен
  только на открытой главной странице с работающим соединением.
- Таймеры опроса UI отключаются при document.hidden; при возвращении статус обновляется.
  Запросы одного типа не накладываются. Фоновые сетевые задачи и VPN продолжают работу.
- В состоянии покоя zapret опрашивается раз в 10 секунд только в своём разделе;
  при задаче — раз в 1,5 секунды. Состояние обновлений SVOI — раз в 30 секунд,
  при загрузке/проверке — раз в 1,5 секунды.
- UI запрашивает `/api/zapret?summary=1`: последние 400 результатов и общие счётчики.
  Полный JSON загружается через `/api/zapret` только при экспорте. Чтение каталога
  стратегий больше не удерживает mutex журнала и прогресса.
- Release EXE собирается с `-s -w`. На одной и той же промежуточной сборке размер
  снизился с 13 933 056 до 10 414 592 байт (~25%). Это удаление отладочных таблиц,
  а не доказательство уменьшения рабочего набора памяти. Для отладки собирайте
  без этих флагов. Node/jsdom нужны только разработчику; в установщик не входят.

## Повторение проверок

```powershell
npm ci --ignore-scripts
npm test
go test ./... -count=1
go vet ./...
go test -run '^$' -bench 'Benchmark(Connection|Zapret)Polling' -benchmem -count=3
```

Дальнейшие измерения: холодный/повторный запуск окна; рабочий набор и CPU всего дерева
SVOI/WebView2/Xray в простое, при сворачивании и при TUN; переключение больших подписок;
пиковая память параллельных Xray-проверок. Сетевую скорость нужно сравнивать на одинаковом
профиле и канале. Данная версия не заявляет ускорения VPN, снижения RAM всего дерева
процессов или изменения совместимости TUN с zapret.
