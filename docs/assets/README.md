# Изображения для README

`hero.png` — фирменная композиция с утверждённым знаком SVOI. Остальные PNG — рендер текущих Flutter-компонентов версии 0.5.0-beta.2 с демонстрационными данными, без подключения к VPN.

Названия Finland, Italy и France соответствуют названиям на предоставленных пользователем снимках. Сетевые адреса заменены на example.com, ключей и ссылок на реальные подписки нет. «Пример подписки» и три записи служат только для демонстрации интерфейса. Никаких замеров скорости или задержки на этих изображениях нет.

Снимки: `overview.png`, `servers.png`, `applications.png`, `zapret.png`, `settings.png`, `selector.png` — 1440 × 960. Баннер — 1440 × 620.

Пересоздать на Windows из каталога `flutter_client`:

```powershell
flutter test --no-pub tool/launch_preview_test.dart
```

Нужны установленные зависимости Flutter и системные шрифты Segoe UI. Скрипт также создаёт локальные постановочные кадры для согласования ролика в игнорируемой папке `.ui-preview/launch`; они не являются записью живого соединения.
