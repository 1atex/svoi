# История изменений после обновления

## Короткое знакомство

Первая установка и новая версия открывают два коротких шага: выбор из восьми тем с живым превью, затем предложение посмотреть изменения установленной версии. Текущая тема предвыбрана и не сбрасывается. Выбор применяется и сохраняется сразу; VPN, подписки и правила не меняются. «Пропустить», крестик, Escape и системная кнопка назад закрывают знакомство. Завершение или пропуск записывается для текущей версии; повторный запуск и переустановка той же версии не открывают его снова. Переход на следующую версию снова предлагает знакомство.

При запуске в трей показ ждёт явного открытия окна. Также он откладывается до окончания подключения и закрытия другого диалога. Фонового таймера нет. После пропуска остаётся компактная ссылка «Что нового»; после завершения второго шага она скрывается, чтобы не дублировать предложение.

В `release-notice.json` дополнительно сохраняются `onboardingVersion` и `onboardingFirstInstall`. Отсутствие этих полей у старой установки даёт одно знакомство с новым механизмом. Тема по-прежнему находится в отдельном `appearance.json`.

Проверки: `flutter test test/onboarding_test.dart`. Включены сохранение темы, переходы вперёд/назад, Skip/Escape, ошибка браузера, окно 800×600 и 320×640 с текстом 150%, старт в трее и отложенный показ поверх других диалогов.

## Ссылка на изменения

Клиент показывает компактное предложение «Что нового» после перехода на более новую установленную версию. Браузер открывается только по нажатию. Закрытие предложения сохраняется до следующего обновления. Старт в трей не вызывает диалогов и не поднимает окно.

Windows: установщик сохраняет прежний `DisplayVersion` в секции `Updates` файла `launch.ini`. Это позволяет обнаружить первое обновление с версий, в которых учёта ещё не было. Последующие обновления, в том числе portable, определяются по `release-notice.json` в папке данных. Первая portable-версия с этим механизмом создаёт исходную отметку без предложения. Переустановка той же версии и откат не считаются обновлением.

Android: используется установленная `currentVersion` из PackageManager, а не номер последнего доступного APK. Первый переход с прежних версий определяется по `lastUpdateTime > firstInstallTime`; далее используется тот же файл состояния. Обновление не добавляет периодических запросов или отдельного процесса.

Ссылка содержит точную установленную версию и платформу и по умолчанию ведёт на `https://svoi.space/changelog/?platform=windows&version=...` (для Android и Linux меняется платформа). Отдельная кнопка GitHub открывает исходники `https://github.com/1atex/svoi` и не помечает изменения прочитанными. Дополнительные флаги сборки не требуются. Ошибка открытия браузера сохраняет предложение для повторной попытки.

Это изменение подготовлено после публикации Windows beta.4; её существующие бинарники не заменялись. В beta.4 пока остаётся прежний переход на GitHub Release. Новый адрес будет в следующем выпуске.

История сайта в отдельном проекте `svoi-landing` формируется из опубликованных GitHub Releases: `python scripts/refresh-releases.py` собирает все страницы API и атомарно сохраняет проверенный `dist/releases.json`, затем `python scripts/build-release-site.py` обновляет главную страницу и историю из одного снимка. Версии, ссылки и заметки в `dist/releases.json` вручную не редактируются; исходные заметки исправляются в соответствующем GitHub Release. Подготовленный, но ещё не опубликованный RC в публичный снимок не включается. Для неизвестной версии сайт показывает сообщение об отсутствии заметок и ссылку на полную историю GitHub. Настройка автоматизации и отдельного разрешения на публикацию описана в `svoi-landing/docs/RELEASE-SOURCE.md`.

Проверки: `flutter test test/release_notice_test.dart test/bootstrap_test.dart` для Windows; `flutter test test/release_notice_test.dart test/mobile_updates_test.dart` для Android. Охвачены первая установка, первое обновление через установщик, сохранение и закрытие предложения, откат, числовой порядок beta.8/beta.15, ошибка браузера и узкое окно с увеличенным текстом.
