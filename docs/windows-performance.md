## База измерений — 26 октября 2026

Windows, AMD Ryzen 5 5600X (12 логических процессоров), Go benchmark, release-клиент 0.5.0-beta.8. Это измерения на машине разработчика, а не гарантии для других ПК.

Новые результаты передаются полностью (последние 400 в сводке); полный экспорт сохранён. Клиент также не сериализует повторно большой неизменный массив результатов для сравнения состояния.

В скрытом окне приостанавливаются Flutter tickers и таймеры вкладок zapret/обновлений. При возвращении в окно данные запрашиваются сразу; контроль активного VPN сохраняется.

20-секундный замер уже запущенной beta.8: GUI — около 140 МиБ рабочего набора, backend — 21 МиБ. Средний CPU всего компьютера: GUI 0,019%, backend менее точности измерения. VPN выключен, zapret запущен; видимость окна не контролировалась. Эти числа не являются сравнением до/после и не доказывают отсутствие утечек.

Повторяемый сбор без изменения сети:

```powershell
./scripts/measure-windows.ps1 -Seconds 30 -Label idle-window -Output idle-window.json
```

Повторить отдельно для открытого окна, трея, активного VPN и проверки серверов. После нескольких циклов подключения сравнить число процессов, рабочий набор и приватную память. Для честного сравнения использовать одну сборку/машину, одинаковый профиль и одинаковый интервал. Скрипт не запускает и не завершает процессы и не изменяет подключение. Время запуска и плавность кадров этим скриптом не измеряются.

## Задержка

Основная проверка — HTTPS через временный Xray с выбранным профилем: четыре параллельных слота, общий лимит 4 секунды. Это не ICMP и не скорость загрузки. Результат запроса сохраняется на 24 часа, вместе с временем проверки; отмена повторной проверки сохраняет прежний результат. Новый запуск VPN отменяет очередь проверок.

Меню отдельного узла содержит TCP-проверку адреса с лимитом 2 секунды. Она не запускает Xray и не подтверждает правильность VPN-конфигурации. Для полного профиля с несколькими узлами она не предлагается.

## DNS

Настройки → Сетевые инструменты → Подобрать DNS. Проверяются текущие IPv4 DNS адаптеров и Cloudflare, Google, Quad9: шесть запросов к трём доменам, максимум три адреса одновременно. Отображаются медиана, максимум и число успешных ответов. Запросы имеют отдельный лимит 1,5 секунды. Рекомендация отображается только без VPN и при шести успешных ответах; результат зависит от кэша и текущего маршрута.

При TUN профиль может перехватить DNS, поэтому результат нельзя надёжно приписать указанному провайдеру. Изменение режима/сервера отменяет текущий тест. Изменение IPv4 DNS Windows требует администратора и отключённого VPN. До первой записи сохраняется исходный статический список или режим DHCP; повторное применение не перезаписывает исходный снимок. Восстановление доступно после перезапуска SVOI. DoH, IPv6, DNS браузера и DNS профиля не меняются.

Проверка через собранный native backend на машине разработчика: все три публичных DNS ответили 6/6 раз; медианы Cloudflare/Google/Quad9 — 36,4/61,3/55,2 мс. Настройки сети не изменялись. Это один замер в конкретной сети, не универсальный рейтинг провайдеров.

Изменение системного DNS использует [Set-DnsClientServerAddress](https://learn.microsoft.com/en-us/powershell/module/dnsclient/set-dnsclientserveraddress?view=windowsserver2025-ps) с IPv4 CIM-объектом выбранного адаптера.

## zapret и TUN

Перед TUN выполняется проверка. Для zapret, запущенного SVOI, доступно переключение с разовым согласием или сохранённой настройкой. Процесс останавливается с ожиданием завершения; стратегия возвращается после отключения VPN или неудачного запуска. Ошибка возврата не теряет данные для повторной попытки. Сторонние winws/winws2 не завершаются: пользователь получает предупреждение. Совместная работа TUN и zapret не заявляется.

Автотесты покрывают координацию, отмену запросов, сохранение результатов, откат DNS и отказ изменения во время VPN. Проверка реального переключения TUN/zapret с правами администратора и реальная запись/восстановление DNS на адаптере требуют отдельного системного прогона; тесты используют подмену системного интерфейса и не меняют сеть разработчика.
