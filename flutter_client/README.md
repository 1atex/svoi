# SVOI — 0.5.0-beta.1

Windows-клиент на Flutter 3.47 / Dart 3.13. Сетевой движок и обработка подписок остаются в Go / Xray. Устанавливается отдельно от прежнего WebView-клиента.

## Запуск

Запустите установщик `SVOI-Flutter-0.5.0-beta.1-windows-x64-setup.exe`: он создаст ярлыки и предложит запустить приложение. Для portable-версии распакуйте **весь архив** и запустите `svoi_flutter.exe`. В архив входят Go-сервис, Xray, Wintun, базы GeoIP/GeoSite и библиотеки Visual C++. WebView2 этому окну не нужен. В установщике ярлык на рабочем столе и запуск от администратора для TUN / zapret включены по умолчанию; флажки можно снять. Windows запрашивает UAC при запуске. Проверку начинайте с отключённым VPN в основном клиенте.

Данные сохраняются отдельно: `%APPDATA%/SVOI-Flutter`. Подписку можно добавить ссылкой, текстом конфигурации или кодом переноса SVOI1. Перед импортом показан состав профиля; можно добавить новый или подтвердить замену текущего. Обычная установка SVOI не меняется. Повторный запуск Flutter поднимает уже открытое окно.

## Интерфейс

В установщике есть отдельный флажок «Всегда запускать от имени администратора». Он сохраняется для этой установки и действует при запуске через ярлык и напрямую через EXE. Windows покажет стандартное подтверждение UAC; повторный ручной перезапуск не нужен. Уже открытый клиент просто поднимается на передний план. При отмене UAC можно явно выбрать запуск без повышения прав. Чтобы отключить настройку, запустите установщик снова и снимите флажок. Portable по умолчанию запускается без повышения прав.

Вкладка серверов использует компактные строки, отмечает реально активный сервер и показывает число результатов после фильтрации. В zapret управление, проверки и журнал разделены вкладками; на широком окне результаты видны рядом с настройками проверки. Доступен фильтр проблем, подробности результата и полный отчёт.

Главная карточка объединяет сервер, питание, режим и состояние соединения. Быстрый доступ показывает избранное и последний запущенный сервер; данные сохраняются отдельно для каждого профиля. В списке доступны фильтр избранного, сортировка по задержке внутри групп (избранные / последний / остальные), время проверки и конфигурация сервера. Неудачная проверка не запрещает подключение.

Запуск Xray и успешная HTTPS-проверка — отдельные состояния. Диагностика содержит ошибку, время проверки, порты и журнал. При смене сервера, режима или правил приложений отображаются активные настройки и ожидающие применения.

Круглая кнопка питания включает или выключает VPN; доступна с клавиатуры через Tab и Enter / Space. Если выбраны другие сервер или режим, их применение предлагается отдельной кнопкой, а круг по-прежнему отключает активное соединение. Контурный фон статичен и не использует фоновые таймеры.

Собственная графитовая тема с янтарным акцентом, компоненты `shadcn_ui`, иконки Lucide и локальные SVG-флаги `country_flags`. Список серверов создаётся лениво; страна вычисляется при загрузке подписки, без GeoIP-запросов. Поддерживаются префиксы `nl`, `[NL]`, `(NL)`, emoji и распространённые названия стран. Неизвестное расположение отмечается глобусом. Настройка Windows уменьшения анимации учитывается для переходов и состояния подключения. Шрифт Segoe UI используется из Windows без загрузки из сети.

## Реализовано

- Подключение через существующий Xray: локальный прокси, системный прокси Windows, TUN.
- Несколько подписок, ручное обновление и обновление при запуске.
- Поиск, выбор сервера, HTTPS-проверка через Xray в четыре потока с отменой.
- Просмотр исходной и подготовленной конфигурации; правила маршрутизации обрабатывает тот же Go-код, что в основном клиенте.
- Журнал, проверка соединения, остановка сервиса при закрытии окна.
- Ленивый список, локальные обновления состояния строк, приостановка опроса при сворачивании.

- Несколько локальных профилей, переключение, импорт с предпросмотром, экспорт кода / файла .svoi, редактирование параметров запроса.
- Настройки, переименование, удаление и экспорт подписок; фильтр серверов по источнику.
- Правила приложений для TUN: все / включить выбранные / исключить выбранные; выбор EXE через диалог Windows.
- zapret: скачивание и обновление из Flowseal, стратегии, запуск/остановка, диагностика Windows, проверки сайтов, DPI-checkers, перебор выбранных стратегий, отмена, полный JSON-отчёт и журнал.
- Обновления приложения: проверка, автоматическое скачивание, SHA-256, установка по команде пользователя.
- Трей: кнопка в шапке прячет окно; значок открывает его, контекстное меню позволяет отключить VPN и выйти. Крестик завершает приложение и сервис.
- Короткие переходы страниц с учётом системной настройки уменьшения анимации; управление с клавиатуры, компактная прокручиваемая навигация, нейтральная тёмная тема.

Android/iOS runner ещё нет. Настройки запущенного туннеля меняются после переподключения. Совместимость TUN со сторонним zapret зависит от его стратегии и сетевой конфигурации: перенос UI не исправляет такие конфликты автоматически.

## Сборка

Windows x64, Flutter 3.47.7, Go 1.26, Visual Studio с C++ Desktop workload, Inno Setup 6. Положите Xray/Wintun и базы в корневую `core/` по инструкции основного проекта.

```powershell
./flutter_client/build-prototype.ps1 -FlutterSdk C:/path/to/flutter
```

Скрипт выполняет анализ, тесты, release-сборку, добавляет runtime и создаёт ZIP и установщик с SHA256 в `releases/flutter-v0.5.0-beta.1`. Перед упаковкой проверяются имя приложения и все кадры иконок окна / трея внутри собранного EXE. SDK и артефакты не попадают в Git. `-SkipChecks` нужен только для повторной упаковки уже проверенных исходников.

Backend запускается дочерним процессом на случайном loopback-порту; одноразовый ключ передаётся через pipe, а не командную строку. При закрытии stdin сервис останавливает Xray и восстанавливает настройки системного прокси. Токены локальных профилей хранятся в session.json, как секрет профиля: не публикуйте эту папку.

`--demo` запускает только UI с 1000 фиктивных серверов без VPN. Для изолированных проверок доступны переменные `SVOI_FLUTTER_DATA` и `SVOI_BACKEND`.

## Проверки и ограничения оценки

Widget-тесты проверяют список из 1000 серверов, поиск, выбор, JSON и окно 800×600. Тест контроллера проверяет предел четырёх запросов и отмену. Интеграционный тест запускает настоящий Go backend и Xray, проводит HTTP-запрос к loopback-серверу через правило импортированного профиля, проверяет JSON, настройки подписки, перенос, сохранение сессии и завершение процесса. Внешние VPN-серверы и системные маршруты в тесте не используются. Widget-тесты также проверяют навигацию по всем страницам, вызовы запуска/отмены проверок zapret и сохранение правил приложений. Реальный WinDivert/TUN требует отдельной проверки с правами администратора.

Flutter не гарантирует уменьшение памяти или ускорение VPN. Замерять следует release-сборки с одинаковым профилем, включая дочерние процессы. Скорость туннеля определяется Xray, маршрутами и сетью; смена интерфейса её сама по себе не повышает.

## Публикация обновлений

Канал использует релизы `1atex/svoi`, но принимает **только** файл `SVOI-Flutter-<версия>-windows-x64-setup.exe`. WebView-установщики `SVOI-…` отвергаются. Для выпуска обновите `pubspec.yaml`, `clientVersion` в Dart и `nativeVersion` в Go, затем соберите с тем же `-Version`. Опубликуйте установщик и ZIP в GitHub Release с тегом `v<версия>`; GitHub API должен возвращать SHA-256 digest для установщика. До публикации пользователи эту сборку автоматически не получат. Beta публикуется обычным Release с отметкой Latest; prebeta и rc — как prerelease.

Первый переход с WebView выполняется установщиком Flutter и переносом профиля. Автоматически мигрировать рабочие данные старого клиента эта сборка не пытается. После перехода следующие Flutter-релизы скачиваются внутри приложения; страницу GitHub пользователю открывать не требуется.
