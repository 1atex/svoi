# SVOI Android 0.1.0-preview.14

- Настройки разделены на секции, профиль доступен в настройках.
- Убраны отдельная группа «Избранные и недавние» и повторяющиеся подписи у кнопки включения.
- Порядок подписок можно менять перетаскиванием или через меню; он сохраняется между запусками.
- В списке серверов отображается тип протокола. Неответившие серверы отмечены нейтральным n/a.
- User-Agent новых подписок по умолчанию — Happ/0.4.1; пользовательские значения сохраняются.
- Рядом с названием подписки доступна проверка задержки только её серверов.
