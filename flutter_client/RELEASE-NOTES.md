# SVOI Android 0.1.0-preview.12

- Четыре вкладки: подключение, серверы, инструменты и настройки. Общий профиль, перенос подписок и параметры HWID находятся в «Настройки → Общий профиль».
- На вкладке «Инструменты» доступны интернетометр, сравнение DNS и проверка сайта по текущему соединению. Изменение системного DNS в Android не добавлено.
- Тема AMOLED получила чистый чёрный фон. Иконки интерфейса можно выбрать контурные или двухцветные; цвет следует за темой.
- В интернетометре добавлены флаги в список выбора и результаты. Профили проверяются встроенным Xray; системный VPN для теста не включается, и трафик других приложений не измеряется.
- В импорте есть кнопка «Вставить». Диалог остаётся доступным с открытой клавиатурой; текст можно отредактировать.
- Обновлены адаптивные значки приложения, включая монохромный вариант Android.

**Телефон Xiaomi/Redmi/POCO и другие ARM64:** скачайте `-arm64.apk`.
**Эмулятор Android Studio x86_64:** скачайте `-x64.apk`.

Android 8+. Пакет `dev.svoi.app.preview` и постоянная подпись сохранены. Обновление поверх предыдущей версии с этой подписью проверено; удалять приложение не требуется.

Проверены тесты Flutter и встроенного ядра, подключение и переподключения в эмуляторе Android API 35, а также обновление подписанного APK с сохранением данных.

Обновление проверяется и скачивается из SVOI. Установка APK требует подтверждения пользователя. Каналы обновлений Android и Windows независимы.
