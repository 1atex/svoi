# SVOI 0.7.1 RC1 — Windows

- Более компактное окно 980×700 и обновлённый экран подключения. Выбранный сервер, IP и параметры соединения собраны рядом со списком; дополнительные параметры раскрываются по нажатию.
- Кнопка подключения с круговой шкалой, анимацией нажатия и световым импульсом после запуска соединения. При включённом VPN на кнопке отображаются состояние и время подключения.
- Выбор другого сервера при работающем VPN сразу переключает соединение. При выключенном VPN выбор сервера только сохраняется. Повторные нажатия во время переключения блокируются, ошибки остаются доступны в диагностике.
- Плавная смена флага и названия выбранного сервера. Обновление подписки показывает вращение значка и краткое подтверждение успеха; отмена и ошибка не отображаются как успешное обновление.
- Короткие уведомления после обновления и импорта подписок. При обновлении нескольких источников показывается общий результат. Уведомления можно закрыть; при наведении они остаются на экране.
- Переработано добавление подписки: ссылка или текст конфигурации, код SVOI и файл. Вставка из буфера — по кнопке; выбранный файл подтверждается перед добавлением, код SVOI открывает просмотр состава профиля.
- Автозапуск Telegram-прокси вместе с Windows. Настройка доступна в разделе автоматизации и панели Telegram-прокси; она включает запуск SVOI в трее. Обычный ручной запуск приложения не включает прокси автоматически.
- Анимации учитывают системное уменьшение движения. В простое нет постоянно повторяющихся декоративных анимаций.

Windows 10/11 x64. Установщик и portable ZIP содержат ядра и необходимые библиотеки. Portable нужно распаковать полностью. Для TUN и zapret нужны права администратора. Подписки и настройки сохраняются отдельно от файлов приложения.

Это Release Candidate для проверки перед стабильным выпуском. Пакет обновления проверяется подписанным манифестом Ed25519 и SHA-256; Authenticode-подписи Windows у приложения нет.
