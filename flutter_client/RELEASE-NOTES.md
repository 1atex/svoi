- Настройки разделены на понятные секции. В Windows исправлена кнопка «Назад» внутри секций.
- Убрана отдельная группа «Избранные и недавние» и повторяющиеся подписи под кнопкой включения. Сохранённые избранные доступны через фильтр.
- User-Agent новых подписок по умолчанию — Happ/0.4.1. Пользовательские значения сохраняются; форматы sing-box и Mihomo запрашиваются отдельно.

Подписки и настройки сохраняются. Обновление доступно внутри SVOI с проверкой подписанного манифеста.

## Предыдущие изменения

# SVOI 0.7.0 Beta Release Candidate 2 — Windows

- Переключение Xray, sing-box и Mihomo сохраняет экран серверов, названия подписок и раскрытые группы. Подписки без подходящего формата остаются на месте с недоступным выбором и нейтральным пояснением.
- Подписки можно перетаскивать за ручку у названия. Порядок сохраняется между запусками; через меню ручки также доступны действия «Выше» и «Ниже».
- Неответившие серверы показывают `n/a`. Причина и повторная проверка доступны по нажатию; отсутствие результата пинга само по себе не запрещает подключение.
- При обновлении подписки сохраняются отдельные варианты для Xray, sing-box и Mihomo. Для sing-box и Mihomo используется формат, выданный провайдером, с его DNS и маршрутизацией. Узлы доступны для отдельного выбора без ручного извлечения копий.
- Добавлен TUN для sing-box и Mihomo на Windows. Исправлены ошибка DNS `detour to an empty direct outbound` и преждевременное определение готовности ядра. Для TUN нужны права администратора; выбор отдельных приложений для этих двух ядер пока не поддерживается.
- Проверка задержки отдельных узлов через sing-box/Mihomo проверяет выбранный узел, исключая ложный успех через прямой маршрут профиля. В списке виден тип протокола, включая Hysteria2.

Установщик и portable ZIP включают все три ядра и необходимые библиотеки. Для portable-версии распакуйте архив полностью. Подписки и настройки сохраняются при обновлении. Это Windows RC; отдельные Android, iOS, macOS и Linux пакеты этим выпуском не заменяются.

Обновление внутри SVOI проверяет подписанный манифест. Authenticode-подписи установщика пока нет, поэтому предупреждение Windows SmartScreen при ручной установке возможно.

## Предыдущие изменения

# SVOI 0.7.0 Beta Release Candidate

Техническая версия: `0.7.0-rc.1`. Кандидат для проверки, не стабильный выпуск.

- Исправлен пинг через sing-box/Mihomo для узлов со стандартными Reality-параметрами и отключённым mux. Несовместимый полный профиль теперь показывает «Нужен Xray», ошибка запуска — «Ошибка ядра», а «Нет ответа» означает истечение времени проверки.
- Из полного Xray-профиля можно явно создать отдельные копии узлов. Исходный профиль сохраняется; копии не содержат его маршрутизацию, DNS, балансировку и резервные маршруты и не обновляются вместе с подпиской. Это предупреждение показывается перед созданием.
- При смене ядра очищаются текущие и сохранённые результаты пинга. Подмена отпечатка TLS или ослабление проверки сертификата не выполняется.

- Круглая кнопка подключения содержит только значок; подсказка, доступное имя, загрузка и состояния соединения сохранены.
- «Проверить пинг» — кнопка с иконкой, результатом в мс и состояниями проверки/ошибки. Измеряется HTTP GET через выбранный профиль, а не ICMP.
- Реальные Xray, sing-box 1.14.4 и Mihomo 1.19.33. Дополнительные ядра поддерживают простые VLESS, VMess, Trojan и Shadowsocks, TCP/WS/gRPC и поддерживаемые TLS/Reality параметры. Windows: ручной/системный прокси; Linux: ручной прокси. TUN, полные профили и собственные правила остаются у Xray. Неподдерживаемая конфигурация отклоняется явно.
- При включённых автозапуске SVOI и проверке обновлений Windows показывает уведомление о новой версии. «Напомнить завтра» и «Пропустить версию» сохраняются между запусками.
- Обновление по команде пользователя: проверка подписанного манифеста Ed25519 или доверенной подписи Authenticode, SHA-256, резервная копия пользовательских данных, установка полного пакета в фоне и перезапуск. При проверке подписи с ошибкой активное подключение не прерывается.
- Сайт получает версии, историю, ссылки и общий счётчик скачиваний файлов из одного проверенного снимка публичных GitHub Releases. RC появляется среди загрузок только после фактической публикации.

Подписки и настройки находятся отдельно от приложения и сохраняются. Установка использует полный Inno Setup внутри: дельта-обновления и гарантированный автоматический откат файлов приложения не заявлены. Время 20–30 секунд не обещается без измерения реального обновления. При сбое сохраняются журнал и резервная копия данных; предыдущий установщик можно установить вручную.

Для Windows 10/11 x64. Portable ZIP нужно распаковать полностью. TUN Xray требует прав администратора. Authenticode-подписи у этой сборки нет; подписанный манифест SVOI подтверждает подлинность обновления внутри приложения, но не убирает предупреждение Windows SmartScreen при первой ручной установке.

## Подключение и подписки

- VPN становится доступен для отключения и переключения сразу после запуска ядра. Проверка интернета выполняется отдельно; её старые ответы не меняют новое соединение.
- Новая конфигурация проверяется до отключения прежнего сервера. Ошибка в конфигурации сохраняет рабочее соединение.
- Обновление подписок не блокирует подключение, выбор сервера и поиск. У каждой подписки собственные состояние, отмена, причина ошибки и повторная попытка. Сохранённые серверы остаются доступны.
- При обновлении нескольких источников результаты появляются по мере готовности. Смена профиля отменяет прежние запросы и отбрасывает запоздалые ответы.
- Проверка задержки отменяется при подключении и сворачивании в трей; отменённые результаты не подменяют предыдущие измерения.
- Большие JSON-ответы локального сервиса разбираются вне UI isolate. Ошибки подключения и обновления объясняют, какое действие выполнить дальше.

Сетевые инструменты и переключение zapret / VPN.

- Перед TUN SVOI обнаруживает активный zapret. Свой процесс можно приостановить на время VPN с разовым согласием или автоматически. После отключения VPN или ошибки запуска возвращается прежняя стратегия. Сторонние winws/winws2 определяются отдельно; SVOI просит остановить их через исходный лаунчер.
- Проверка задержки сохраняет результаты на 24 часа. При повторной проверке и её отмене прежний результат не теряется. Основной тест выполняет HTTPS-запрос через профиль; в меню отдельного узла появился быстрый TCP-тест адреса с лимитом 2 секунды.
- Настройки → Сетевые инструменты → Подобрать DNS: текущие IPv4 DNS и Cloudflare, Google, Quad9. По шесть запросов, три проверки одновременно, отмена и результаты по готовности. Можно применить DNS выбранного адаптера и восстановить прежние настройки, включая DHCP, после перезапуска.
- Неизменные результаты проверок zapret больше не пересылаются и не сравниваются целиком при каждом опросе. В бенчмарке ответ уменьшился с 79 КБ до 363 байт. Скрытое окно приостанавливает анимации и опрос вкладок zapret / обновлений; контроль работающего VPN сохраняется.

DNS-тест измеряет обычный DNS, не DoH. При TUN запросы могут перенаправляться правилами профиля. Изменение DNS Windows требует администратора и отключённого VPN; IPv6, DNS браузера и профиль Xray не меняются.

Проверены Go/Flutter-тесты, реальное чтение сетевых адаптеров, окно 800×600 и масштаб текста 150%. Системные операции изменения DNS и переключения zapret/TUN покрыты тестами с подменой системного интерфейса; реальный прогон с правами администратора остаётся необходимой проверкой на ПК пользователя.
