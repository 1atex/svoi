# SVOI 0.5.0-beta.6

Исправление автозапуска Windows и штатное отключение Xray.

- Исправлена ошибка Планировщика «The parameter is incorrect … UserId», когда короткое имя пользователя неоднозначно, например совпадает с именем компьютера. Задача сохраняет полный SID текущей учётной записи.
- При отключении Windows-клиент отправляет Xray сигнал штатного завершения и ждёт выхода процесса. Ядро получает возможность очистить TUN, маршруты и DNS. Принудительная остановка используется только если процесс не завершился за 5 секунд; это отмечается в журнале.
- Состояние «Отключаемся…» сохраняется до завершения процесса и восстановления системного прокси. Новый запуск не пересекается с остановкой предыдущего.
- Подключение ожидает завершения инициализации Xray, а не только открытия локального порта. Для настройки TUN предусмотрено до 20 секунд.
- Отключение отменяет текущую проверку интернета. Её запоздалый результат не меняет состояние остановленного или нового подключения.
- В интерфейсе используется «кнопка включения». Для работающего VPN действие по-прежнему подписано «Отключить VPN».
- При ошибке автозапуска отображается причина от Планировщика Windows, включая тайм-аут, вместо общего сообщения о сохранении.

Проверены повторные подключения через настоящий Xray и локальный тестовый VLESS-сервер, штатный выход процесса и ожидание очистки Windows. Это не проверка доступности конкретной подписки или совместимости TUN с zapret на всех сетях.

Автозапуск приложения и zapret, перенос данных из прежней папки и обновление из приложения сохранены. Direct для российских сервисов остаётся отложенным.
