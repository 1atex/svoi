# SVOI 0.5.0-beta.7

Исправление запуска приложения вместе с Windows.

- Если при входе в Windows не удаётся создать значок в трее или получить состояние zapret, SVOI сохраняет работающий локальный сервис и показывает окно с предупреждением. Настройки, обновления и VPN остаются доступны.
- Исправлено состояние, при котором открытое окно обращалось к уже закрытому сервису и показывало «Запрос отменён» во всех разделах.
- Остановка локального сервиса теперь явно отличается от отмены отдельного запроса.
- Исходники backend и сборочные скрипты разложены по папкам; инструкции и GitHub Actions обновлены.

Проверены сценарии сбоя трея, ошибки запроса zapret и ошибки инициализации. Исправления автозапуска и завершения Xray из beta.6 сохранены.
