# SVOI 0.7.1 RC2

- Новая вкладка WARP: состояние официального клиента Cloudflare, регистрация, подключение и отключение. WARP не использует вашу VPN-подписку.
- Официальный компонент Cloudflare WARP 2026.8.2115.0 включён в полный пакет. Вкладка WARP открывает системный установщик; регистрация выполняется отдельно после принятия условий Cloudflare.
- Проверяется SHA-256 компонента перед запуском установщика. Windows дополнительно проверяет подпись Cloudflare. WARP не удаляется вместе с SVOI и продолжает работать отдельной системной службой.
- SVOI предотвращает запуск своего VPN поверх активного WARP. На Windows также блокируется одновременный запуск стратегий zapret и WARP из приложения.
- Опрос состояния WARP выполняется только на открытой вкладке и при видимом приложении. Скорость и доступность WARP зависят от сети, выбор страны выхода не предусмотрен.

Windows: в установщике появился выбор компонента WARP. При автоматическом обновлении компонент не устанавливается без отдельного выбора пользователя.

Во время обновления Windows отображается окно SVOI со стадиями подготовки, проверки и установки. Основное окно закрывается для замены файлов и открывается снова по завершении. Для перехода с прежних версий установщик также показывает прогресс установки.

Windows 10/11 x64. Требования Cloudflare WARP могут отличаться от требований самого SVOI. В поставке сохранены компактный интерфейс, анимации подключения, уведомления и автозапуск Telegram-прокси из RC1.
