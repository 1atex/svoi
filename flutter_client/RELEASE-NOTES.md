# SVOI 0.5.0-beta.4

Автозапуск Windows, единое имя SVOI и понятное состояние соединения.

- Приложение, EXE и основные установочные файлы называются SVOI. Техническая приставка убрана из интерфейса.
- Данные автоматически переносятся в `%APPDATA%\SVOI` с сохранением подписок, профилей, настроек и установленного zapret. Исходные данные сохраняются как резервная копия.
- В «Настройки → Автоматизация» можно включить запуск SVOI в трее при входе в Windows и запуск последней выбранной стратегии zapret. Включение zapret включает и автозапуск приложения.
- Стратегия zapret сохраняется при выборе и ручном запуске. Автозапуск не выбирает другой вариант, если сохранённая стратегия недоступна: окно открывается с ошибкой.
- Автозапуск работает через Планировщик для текущего пользователя. Для его настройки нужны права администратора; повторного запроса при входе не требуется. Отключение автозапуска SVOI отключает и автоматический запуск zapret.
- При неудачной проверке интернета работающий VPN явно обозначен как включённый. Кнопка питания подписана «Отключить VPN»; проверку можно повторить отдельно.
- Подсказка о правах администратора для TUN скрыта, если необходимые права уже есть.

VPN при входе в Windows автоматически не подключается. Закрытие SVOI останавливает zapret; для работы в фоне используйте трей. Ограничение совместного запуска TUN и zapret сохранено. Direct для российских сервисов отложен на следующие патчи.

Скачайте `SVOI-0.5.0-beta.4-windows-x64-setup.exe` или установите обновление из приложения. Portable: `SVOI-0.5.0-beta.4-windows-x64.zip`, запуск — `svoi.exe`. Закройте SVOI перед ручной установкой.
