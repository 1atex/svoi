# SVOI для Windows

На связи со своими.

## Первый запуск

Запустите `svoi.exe`. Вставьте ссылку на подписку либо импортируйте профиль из файла или кода. Выберите сервер и нажмите «Подключить».

Установщик содержит необходимые компоненты. При использовании portable-версии распакуйте весь архив, включая папки `backend` и `data`.

## Оформление

В «Настройки → Оформление» доступны классика, светлая, системная, океан, изумруд, роза, AMOLED и Хэллоуин. Выбор применяется сразу и хранится локально в `%APPDATA%\SVOI\appearance.json`. Перенос профиля не меняет тему другого устройства. Смена темы не отключает VPN.

## Автозапуск

В «Настройки → Автоматизация» доступны два переключателя:

- Запускать SVOI при входе в Windows — приложение откроется в трее, VPN подключается вручную.
- Запускать zapret вместе с Windows — включает автозапуск приложения и последнюю выбранную стратегию. Сначала выберите или запустите стратегию на странице zapret.

Для изменения автозапуска нужны права администратора. Настройка применяется к текущему пользователю Windows. Планировщик запускает приложение с нужными правами без повторного запроса UAC при каждом входе.

Закрытие SVOI завершает VPN и zapret. Чтобы оставить их работающими, сверните приложение в трей. Если автозапуск zapret не удался, SVOI откроет окно с ошибкой.

## Данные и обновления

Подписки и настройки находятся в `%APPDATA%\SVOI`. При первом запуске beta.4 данные из прежнего каталога переносятся автоматически. Исходная папка сохраняется как резервная копия; существующие данные прежнего клиента сохраняются отдельно в `SVOI-backup-…`.

Обновления доступны в настройках приложения. Файлы проверяются по SHA-256 перед установкой. Не публикуйте папку данных и коды переноса: они содержат доступ к вашим подпискам.

## Соединение

Надпись «VPN включён» означает, что ядро запущено. Отдельная проверка интернета обращается к одному контрольному адресу; её ошибка не отключает VPN. На кнопке включения явно указано «Отключить VPN».

TUN и zapret требуют прав администратора. Их одновременный запуск через SVOI пока заблокирован из-за возможных конфликтов. Автоматический запуск VPN и правила direct для российских сервисов в этот релиз не входят.
