SVOI — предварительная версия для Windows 10/11 x64

Установщик разместит приложение, Xray, Wintun и геоданные в одной папке и создаст ярлыки. Самостоятельно переносить core не нужно.

Если Microsoft Edge WebView2 Runtime отсутствует, он будет загружен и установлен с серверов Microsoft. Для этого потребуется интернет. При наличии WebView2 установка SVOI работает без сети.

Перед обновлением отключите VPN и закройте все окна SVOI, в том числе переносную версию. Для режима TUN запускайте SVOI через «Запуск от имени администратора» в меню ярлыка.

Ваши подписки и профили сохраняются в %APPDATA%\SVOI. Установщик и удаление приложения не стирают эти данные.

Готовая VPN-подписка в комплект не входит. APK и IPA пока отсутствуют.
