# Завершение UDP в Xray TUN

Xray закреплён на `1b1647cd9ddf` (26.10.21). При `stack.Close()` закрывались TCP и локальные UDP-сокеты, но не очереди входящих Full Cone UDP-потоков. Заблокированные читатели могли оставаться после отключения Android VPN.

`xray-tun-close.patch` закрывает эти очереди и запрещает создание новых UDP-потоков после закрытия. Снимок контекста и SHA-256 оригинальных файлов находятся в JSON. Скрипт `scripts/prepare-xray-patch.py` создаёт изменённые копии только в `.tools/xray-patched/`; глобальный кеш Go не изменяется. Мобильный go.mod указывает на эту копию через `replace`. Перед тестированием и сборкой выполните `python scripts/prepare-xray-patch.py` из корня проекта.

Регрессия: `TestTUNStackCloseUnblocksUDP` на оригинальном ядре завершается ошибкой, с overlay проходит. Дополнительно Android CI проверяет 20 циклов TUN и рост горутин/дескрипторов. Пороги этой проверки не изменялись.

Исходники Xray и лицензия MPL-2.0: https://github.com/XTLS/Xray-core/tree/1b1647cd9ddf . Изменения двух файлов Xray распространяются на тех же условиях MPL-2.0; исходный код и патч доступны в этом репозитории. Остальная лицензия проекта не меняется.
